## 1. 稽核範圍、方法與判定標準

### 1.1 專案是什麼

這個倉庫把 PS2《God of War》(NTSC-U `SCUS-97399`) 的 MIPS R5900 可執行檔**靜態重編譯成 C++**，
用 vendored 的 [PS2Recomp](engine/runtime/PS2Recomp) fork 作為 runtime（EE + IOP + GS + VU1 + SPU2），
外面包了一個 Qt 6 / QML 的安裝器與啟動器（`gow-launcher.exe`），以及一條以 PowerShell 為主、
Python 為輔的一鍵建置管線。第一方改動在 vendored 樹內以 `// GOW-Port:` 標記
（實測 520 個標記散布在 351 個檔案），功能面改動集中在以下位置：

| 層 | 位置 | 職責 |
|---|---|---|
| 遊戲功能移植 | `engine/runtime/src/gow_overrides.cpp`、`ps2xRuntime/src/lib/gow_*.cpp` | 掛鉤/取代遊戲函式：緩存、鎖定、QTE、改图、影片跳過、IOP 音效委派 |
| EE runtime | `ps2xRuntime/src/lib/ps2_runtime.cpp`、`ps2_memory.cpp`、`vu/`、`gs/` | 記憶體、排程、VU1 JIT、GS 執行緒與 GPU 後端 |
| IOP | `ps2xIOP/src/**` | IOP CPU/核心/記憶體、CD、音效、記憶卡、RPC |
| 重編譯器 | `ps2xRecomp/src/lib/**`、`config/recomp.template.toml`、`funcmap.csv` | MIPS→C++ 碼生成、跳躍/分支/FPU/MMI/VU 翻譯 |
| 啟動器 | `engine/runtime/launcher/**` | 圖形卡偵測、設定→環境變數交接、ISO/ELF 檢查、啟動 `ps2EntryRunner` |
| 工具鏈 | `tools/**`（Python + PowerShell） | 光碟匯入（ISO/CHD）、區域識別、PGO、patch 堆疊、打包、mod 管理 |
| 配置/文件 | `games/**`、`engine/patches/**`（72 個）、`docs/**` | 每遊戲資料、patch 堆疊、文件 |

### 1.3 審查方法

採「**九路平行深讀 + 主代理獨立取證**」的結構：

1. 九個審查面各自逐檔完整閱讀（非抽樣），範圍見 §1.1 表格。
2. 主代理另外做**可執行取證**，避免只靠靜態閱讀：
   - 解析 `data/mods/reports/*.json` 與 9 次真實執行的 `stderr.log`/`stdout.log`（當天產生）；
   - 以正規運算式做啟動器↔runtime 的環境變數契約集合比對；
   - 盤點 patch 堆疊編號與文件引用一致性；
   - 交叉核對倉庫自身文件（`docs/mod-manager-design.zh-CN.md`、`docs/research/*`）對同一問題的既有結論，
     以避免把「已被承認的死碼」誤報為新發現，也把「文件承認但程式碼未清理」列為真實缺陷。
3. 對每個發現都要求：**位置（檔:行）＋原始碼逐字引用＋根因＋觸發條件＋使用者可見影響＋修法＋信心**。
4. 排除項：`PS2Recomp/ps2xRuntime/src/runner/*.cpp`、`ps2xIOP/src/native/iopn_*`、`build/*/vu1_generado`
   等**生成檔**（AGENTS.md 明訂不得手改）；`third_party`；`data/_tools`（下載的 toolchain）。

### 1.4 嚴重度分級

| 等級 | 定義 |
|---|---|
| **Critical** | 當機、任意主機記憶體越界、使用者存檔/遊戲檔毀損、安全漏洞（注入/路徑穿越/下載未驗證）、資料不可逆遺失 |
| **High** | 主要功能在常用路徑下失效（音效、存檔、影像設定、安裝/更新失敗）、效能或穩定性明顯受損 |
| **Medium** | 特定設定/區域/硬體條件下行為錯誤；診斷誤導；契約漂移但可繞過 |
| **Low** | 外觀、可用性建議、維護性、文件措辭 |

信心標記：**確認**（已追蹤完整路徑或有執行證據）／**高**（讀到兩側程式碼但缺執行驗證）／
**中**（依慣例或上下文推斷）／**低**（需維護者用特定硬體或区域盤驗證）。

### 1.5 本報告的邊界（重要）

- 未進行完整建置（約 6,400 個轉譯單元 + Qt + MSVC/clang，超出可行時間），
  因此**所有編譯期論證來自程式碼與 patch 文本，而非編譯器輸出**；每個需要編譯驗證的發現都標明망
  應跑的目標名稱（例如 `ninja -C build ps2EntryRunner`、`ps2xTest` 的特定測試檔）。
- 未執行需要真實遊戲檔的測試；`zs.iso` 存在於磁碟但我未掛載或解析它。
- 未做實際執行期動態分析（無 debugger/profiler 附加）；執行期證據一律取自倉庫內已有的 9 份 run 記錄。
