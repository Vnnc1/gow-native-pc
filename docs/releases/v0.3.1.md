English · [Português abaixo](#português)

A native PC port of God of War (PS2, NTSC-U `SCUS-97399`). The game's code is statically recompiled from MIPS to
C++ and built on your machine from your own disc image. It is not an emulator. No game files are included or
downloaded.

> **Not 100% yet.** The game is playable and faster in this release, but a locked 60 fps in heavy combat is not there
> yet. Every release improves on the last; **texture packs, a Linux port and ISO mods** are planned.

### Download

* `gow-native-pc-setup.exe` (recommended): installs the launcher for your user only, with no administrator rights.
* `gow-native-pc-windows.zip`: the same files without the installer.

Already on v0.3.0? The launcher offers this update by itself. The runtime patches changed, so it then asks you to
rebuild the game once (Install → the notice at the top). Afterwards the Home page recommends the profile-guided
optimisation again (PGO, Install → More options): run it to get the full speed.

### How to play

1. Run the setup and open God of War Launcher.
2. Install tab, three steps: Download tools → Add ISO… → Install and build. Leave **Prepare the first play** enabled.
3. Wait on the loading screen, pick a graphics profile on the Graphics page, then click PLAY.

The first install takes about 25–30 minutes on a 6-core CPU (with PGO) and about 40 minutes on a 2-core/4-thread
CPU (without PGO). You can keep using the PC while it runs.

### Requirements

* Windows 10/11 64-bit
* x86-64 CPU with SSE4.2 (Intel Core i from ~2009, AMD FX / Ryzen from 2011); the launcher now checks it before installing
* 8 GB RAM (16 GB recommended while building)
* GPU with OpenGL 4.3 (with `NV_texture_barrier` / `ARB_texture_barrier`, as Intel HD 4000–4600 drivers have) or newer
* your God of War (USA, SCUS-97399) ISO, or a fan translation of it that only changes text

### What's new since v0.3.0

Measured on our test PC (Xeon E5-2666 v3 + RX 580, full screen, save route, alternating pairs):

**Performance**

* **Faster VU1 code**, same results bit for bit: average about 51 → **57 fps**, heavy combat about 51 → **55 fps**.
* **Cheaper hand-off to the GS thread**: about 150,000 fewer thread wake-ups per second, combat +3.5%.
* **VU1 decode on demand and one copy less per GIF packet** (from the
  [gow-native-pc-optimization](https://github.com/huanghuangdaquan-beep/gow-native-pc-optimization) fork).

**Older hardware**

* **Older GPUs** whose drivers stop at OpenGL 4.3–4.5 (Intel HD 4000–4600 and others) now use the GPU renderer
  instead of the much slower software one.
* **CPUs with 4 threads or fewer** install faster: the profile-guided pass is skipped (you can run it later) and one
  more compiler runs in parallel.
* **CPUs without SSE4.2** are told before the install instead of failing after it.

**Install and updates**

* Dependencies are downloaded once and without history: the profile-guided step no longer downloads ~1 GB again
  (the slow, low-CPU phase seen on some machines).
* The "rebuild" notice now clears only after a rebuild with the new runtime; after an update the launcher recommends
  training the profile-guided optimisation again.

### Known limitations

* Measured on one machine; the OpenGL 4.3 path was checked by limiting a newer GPU, not yet on an
  Intel HD 4400 itself.
* A locked 60 fps is not reached in heavy combat yet (~55 here); the limit is the VU1 work on one CPU thread.
* Short hitches with audio gaps can occur at area transitions; the PT-BR cutscene audio has a known channel-alignment issue.
* Only the USA disc's code is supported. Windows only for now.

Please report problems in [Issues](https://github.com/Vnnc1/gow-native-pc/issues): **Other → Mark a problem during play**,
then **Other → Test and bug report** to export a ZIP, and include your CPU/GPU.

### Português

Port nativo para PC de God of War (PS2, NTSC-U `SCUS-97399`). O código do jogo é recompilado de MIPS para C++ e
compilado no seu PC a partir da sua própria ISO. Não é um emulador. Nenhum arquivo do jogo é incluído ou baixado.

> **Ainda não está 100%.** O jogo é jogável e mais rápido nesta versão, mas 60 fps travados no combate pesado ainda não
> chegaram. Cada versão melhora; **texture packs, port para Linux e mods de ISO** estão planejados.

Como jogar:

1. Rode o `gow-native-pc-setup.exe` e abra o God of War Launcher.
2. Na aba Instalação: Baixar ferramentas → Adicionar ISO… → Instalar e compilar. Deixe **Preparar a primeira jogatina** ligado.
3. Espere na tela de carregamento, escolha um perfil na página Gráficos e clique em JOGAR.

A primeira instalação leva cerca de 25–30 minutos numa CPU de 6 núcleos (com PGO) e cerca de 40 minutos numa CPU de
2 núcleos/4 threads (sem PGO). Quem já tem a v0.3.0 recebe a atualização pelo launcher, precisa recompilar o jogo uma
vez (aviso no topo da aba Instalação) e depois deve rodar de novo a otimização PGO, que a página Início recomenda.

Requisitos: Windows 10/11 64 bits; CPU x86-64 com SSE4.2 (o launcher agora confere antes de instalar); 8 GB de RAM
(16 GB recomendados ao compilar); GPU com OpenGL 4.3 (com `NV_texture_barrier`/`ARB_texture_barrier`, como os drivers
das Intel HD 4000–4600) ou mais nova; a ISO do God of War (EUA, SCUS-97399).

Novidades:

* **Código da VU1 mais rápido**, com o mesmo resultado bit a bit: média de ~51 para **~57 fps**, combate pesado de ~51
  para **~55 fps**.
* **Envio mais barato para a thread do GS**: ~150 mil despertares de thread a menos por segundo, combate +3,5%.
* **Decodificação da VU1 sob demanda e uma cópia a menos por pacote GIF** (do fork gow-native-pc-optimization).
* **GPUs mais antigas** (driver até OpenGL 4.3–4.5, como Intel HD 4000–4600) agora usam o renderizador por GPU em vez
  do renderizador por software.
* **CPUs de até 4 threads** instalam mais rápido (sem PGO na instalação, um compilador a mais); **CPUs sem SSE4.2** são
  avisadas antes da instalação.
* **Instalação**: as dependências são baixadas uma vez só e sem histórico (a etapa do PGO não baixa mais ~1 GB de novo).
* **Atualizações**: o aviso de "recompilar" só some depois de recompilar com o runtime novo, e o launcher recomenda
  retreinar o PGO.

Limitações: medida em uma máquina; o caminho OpenGL 4.3 foi testado limitando uma GPU mais nova, ainda
não numa Intel HD 4400; 60 fps travados ainda não no combate pesado; pequenos engasgos com falha de áudio em transições;
só o código do disco americano; por enquanto, só Windows.

Relate problemas em [Issues](https://github.com/Vnnc1/gow-native-pc/issues) com o ZIP de **Outros → Relatório de testes
e erros** e informe sua CPU/GPU.
