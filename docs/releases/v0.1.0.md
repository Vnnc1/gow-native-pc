**English** · [Português abaixo](#português)

A native PC port of *God of War* (PS2, NTSC-U `SCUS-97399`): the game's code is statically recompiled from MIPS to C++
and built on your machine from **your own disc image**. It is not an emulator. No game files are included or
downloaded.

## Download

- **`gow-native-pc-setup.exe`** (recommended): installs the launcher for your user only, no administrator rights;
  Start menu / desktop shortcuts and an *Apps* entry to uninstall it.

## How to play

1. Run the setup and open **God of War Launcher**.
2. **Install** tab: install the missing requirements → **Download runtime** → **Add ISO…** → **Install and build**.
   The first build takes 20-60 minutes depending on the CPU. With "Optimize for 60 fps" the game then plays itself for
   about 4 minutes; do not touch it.
3. **PLAY**.

## Requirements

Windows 10/11 64-bit · CPU with AVX2, 4+ cores · 8 GB RAM (16 GB while building) · OpenGL 4.3 GPU · ~25 GB free ·
Visual Studio Build Tools ("Desktop development with C++"), Git and Python 3 (the launcher checks them) ·
your **God of War (USA, SCUS-97399)** ISO, or a fan translation of it that only changes text.

## What's in this release

- **Faster combat with many enemies:** in our scripted ship-combat test with the launcher's default settings, the
  average went from **~48 to ~58 fps**:
  - every block of vector unit code runs as native code (no interpreter fallbacks);
  - the continuous VU1 recording costs almost nothing;
  - faster sound mixing;
  - new "register locals" code generation (about 22 % less work on the game thread).
- **Image fixes at higher internal resolutions**, from the God of War II native port: bloom "ghost", bright edge
  bands, thin lines at 3x, distant geometry disappearing, sprite seams under water. New **anisotropic filtering**
  option (Graphics tab).
- **Correctness fixes:**
  - a CPU instruction translation fix (MOVZ/MOVN);
  - the runtime's internal memory moved out of the game's heap;
  - FMV audio streams, faster memory card saves.
- **Translations:** any fan translation with the original game code is accepted. Its language is detected from the
  disc's text, and the launcher asks which language to play when you add several ISOs.
- **Fresh installs work from GitHub:** runtime patches now keep their line endings, so the install step applies all of
  them.

## Known limitations

- Measured on one machine (Xeon E5-2666 v3, RX 580) with a scripted run of the first level. Other areas
  and hardware are not verified yet.
- The first build is long. "Speed up visited areas" also gets slower over time, because the recorded VU1 data grows
  every session.
- Only the USA disc's code is supported (other regions differ in code).

Please report problems in [Issues](https://github.com/Vnnc1/gow-native-pc/issues) with
`data\gow1\logs\build.log` / `recomp.log` and your CPU/GPU.

## Português

Port nativo para PC de *God of War* (PS2, NTSC-U `SCUS-97399`): o código do jogo é recompilado de MIPS para C++ e
compilado no seu PC a partir da **sua própria ISO**. Não é um emulador. Nenhum arquivo do jogo é incluído ou baixado.

**Como jogar:** rode o `gow-native-pc-setup.exe`, abra o **God of War Launcher** e, na aba **Instalar**, faça:
requisitos → **Baixar runtime** → **Adicionar ISO…** → **Instalar e compilar**. A primeira compilação leva de 20 a 60
minutos. Com "Otimizar para 60 fps", o jogo se joga sozinho por ~4 minutos no final; não mexa. Depois é só **JOGAR**.

**Requisitos:**
- Windows 10/11 64 bits;
- CPU com AVX2;
- 8 GB de RAM (16 GB durante a compilação);
- GPU com OpenGL 4.3;
- ~25 GB livres;
- Visual Studio Build Tools, Git e Python 3;
- a ISO do God of War (EUA, SCUS-97399), ou uma tradução de fãs dela que só mude textos.

**Novidades:**
- **Combate com muitos inimigos mais rápido:** de ~48 para ~58 fps de média no nosso teste do navio, com as opções
  padrão do launcher;
- correções de imagem em resolução interna alta, vindas do port nativo do God of War II;
- nova opção de **filtragem anisotrópica**;
- correções de CPU, memória, áudio de vídeos e memory card;
- **traduções de fãs reconhecidas pelo idioma do texto** (ex.: "Português (Brasil) — tradução de fãs");
- instalação a partir do GitHub corrigida.

**Limitações:**
- medida em uma máquina e só no início do jogo;
- a primeira compilação é longa;
- só o código do disco americano é suportado.

Relate problemas em [Issues](https://github.com/Vnnc1/gow-native-pc/issues), com o `build.log` e o `recomp.log` de
`data\gow1\logs`.
