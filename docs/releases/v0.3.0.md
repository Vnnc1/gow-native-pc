English · [Português abaixo](#português)

A native PC port of God of War (PS2, NTSC-U `SCUS-97399`). The game's code is statically recompiled from MIPS to
C++ and built on your machine from your own disc image. It is not an emulator. No game files are included or
downloaded.

> **Not 100% yet.** The game is playable, but a locked 60 fps is not reached in every scene and only the opening
> areas have been measured in depth. Every release improves on the last, and **texture packs, a Linux port and ISO
> mods** are planned, based on what the community needs.

### Download

* `gow-native-pc-setup.exe` (recommended): installs the launcher for your user only, with no administrator rights.
  It adds Start menu shortcuts and an Apps entry to uninstall it.

Already on v0.2.x? The launcher offers this update by itself. This version changes the runtime patches, so the
launcher then asks you to rebuild the game once. If the Home page then shows **"FPS optimisation recommended (PGO)"**,
run it (Install → More options, about 20 minutes) to get the new performance.

### How to play

1. Run the setup and open God of War Launcher.
2. Install tab, three steps: Download tools → Add ISO… → Install and build. Leave **Prepare the first play** enabled.
3. Wait on the loading screen. Pick a graphics profile on the Graphics page, then click PLAY.

The first install, now including the profile-guided optimisation, takes about 30 minutes on our test PC (longer on CPUs
with fewer cores). You can keep using the PC while it runs.

### Requirements

* Windows 10/11 64-bit
* x86-64 CPU with SSE4.2 (AVX/AVX2 used when present), 4+ cores recommended
* 8 GB RAM (16 GB recommended while building)
* GPU with OpenGL 4.3
* under 10 GB free for one language and one build (estimate; see the README)
* your God of War (USA, SCUS-97399) ISO, or a fan translation of it that only changes text

Visual Studio, Git and Python are not needed. The launcher downloads portable build tools and the clang compiler
once into its own folder (nothing is installed in Windows).

### What's new since v0.2.0

**Performance**

Measured on our test PC (Xeon E5-2666 v3 + RX 580, full screen 1080p, 2× internal resolution):

* Heaviest ship combat: about 40 → **50–53 fps**; ship average about **55 fps**.
* **Early FINISH:** the game now prepares the next frame while the vector unit (VU1) draws the current one. That is
  about **+20% fps in heavy combat**. On by default; *Launcher → Performance → Finish frames early* turns it off.
* **Profile-guided optimisation is now part of the install:** about +5% average and +13% in combat.
* A 30-minute session from a later save stayed stable, with memory flat after warm-up.

**Much faster preparation**

* First-play preparation + profile-guided optimisation in **about 24 minutes**, instead of about 63 for the same work
  before: one training run records the game's code and the performance profile together.
* More compilers in parallel on machines with less RAM per core; the largest generated file builds in 10 s instead of 331 s.
* `build.cmd -Stages verify` regression tests; a single pinned clang (llvm-mingw) toolchain with cached code generation.

**In game: new F1 menu**

* **Graphics** tab, changed live: scaling filter, sharpness, FXAA, anisotropic filtering, FPS limit, VSync, FPS counter, stretch.
* **Cheats** tab (F2 opens it directly) and **Save** tab (copy of the memory card).
* Menu available in Portuguese. The runtime debugger moved to Ctrl+F1.
* FXAA no longer turns off the sharp scaler.

**Launcher**

* Graphics profiles: **Performance / Balanced / Quality**.
* **Borderless fullscreen** and an **Upscaling and tools** section. Lossless Scaling, ReShade and OBS work in borderless
  mode. DLSS and FSR 2–3 are not possible with this renderer, and the section explains why.
* A shortcut to the **keyboard and mouse** bindings on the Controls page.
* PGO status (active / recommended), a Saves page and session reports for bug reports.
* Settings that did nothing were removed (dynamic resolution, sharp image, hardware renderer switch).

**Fixes**

* Memory/DMA correctness, SPU2 audio mix overflow, standalone game launch and many smaller fixes, listed per patch in
  [`engine/README.md`](https://github.com/Vnnc1/gow-native-pc/blob/main/engine/README.md).

### Known limitations

* Measured on one machine (Xeon E5-2666 v3, RX 580) and mostly in the opening areas.
* A locked 60 fps is not reached in heavy combat yet; the limit is now the VU1 work on the CPU.
* Short hitches with audio gaps can occur at area transitions; the PT-BR cutscene audio has a known channel-alignment issue.
* If you see image glitches, turn off **Finish frames early** (Launcher → Performance) and report it.
* Only the USA disc's code is supported (other regions differ in code). Windows only for now.

Please report problems in [Issues](https://github.com/Vnnc1/gow-native-pc/issues). Use **Other → Mark a problem during play**,
then **Other → Test and bug report** to export a ZIP, and include your CPU/GPU.

### Português

Port nativo para PC de God of War (PS2, NTSC-U `SCUS-97399`). O código do jogo é recompilado de MIPS para C++ e
compilado no seu PC a partir da sua própria ISO. Não é um emulador. Nenhum arquivo do jogo é incluído ou baixado.

> **Ainda não está 100%.** O jogo é jogável, mas 60 fps travados ainda não são alcançados em todas as cenas, e só as
> áreas iniciais foram medidas a fundo. Cada versão melhora, e **texture packs, port para Linux e mods de ISO** estão
> planejados, conforme a necessidade da comunidade.

Como jogar:

1. Rode o `gow-native-pc-setup.exe` e abra o God of War Launcher.
2. Na aba Instalação, faça os três passos: Baixar ferramentas → Adicionar ISO… → Instalar e compilar. Deixe
   **Preparar a primeira jogatina** ligado.
3. Espere na tela de carregamento, escolha um perfil gráfico na página Gráficos e clique em JOGAR.

A primeira instalação, agora já com a otimização guiada por perfil, leva cerca de 30 minutos no nosso PC de teste, e
dá para continuar usando o PC enquanto isso. Quem já tem a v0.2.x recebe a atualização pelo próprio launcher e precisa
recompilar o jogo uma vez. Se aparecer **"Otimização de FPS recomendada (PGO)"** na página Início, rode-a (Instalação →
Mais opções, cerca de 20 minutos).

Requisitos:

* Windows 10/11 64 bits;
* CPU x86-64 com SSE4.2 (AVX/AVX2 são usados quando existem), 4+ núcleos recomendados;
* 8 GB de RAM (16 GB recomendados durante a compilação);
* GPU com OpenGL 4.3;
* menos de 10 GB livres para um idioma e uma compilação (estimativa; veja o README);
* a ISO do God of War (EUA, SCUS-97399), ou uma tradução de fãs dela que só mude textos.

Não precisa de Visual Studio, Git nem Python: o launcher baixa ferramentas portáteis e o compilador clang uma vez, na
própria pasta.

Novidades:

* **Desempenho**, no nosso PC de teste (1080p, resolução interna 2×): combate mais pesado do navio de ~40 para
  **50–53 fps**, média ~**55 fps**.
* **Early FINISH:** o jogo prepara o próximo quadro enquanto a VU1 desenha o atual, o que dá cerca de **+20% de fps no
  combate pesado**. Vem ligado; desliga em *Launcher → Desempenho → Antecipar o fim do quadro*.
* **Otimização guiada por perfil (PGO) agora faz parte da instalação:** cerca de +5% na média e +13% no combate.
* Preparação da primeira jogatina + PGO em **~24 minutos**, contra ~63 do mesmo trabalho antes.
* **Novo menu F1 no jogo:**
   * aba Gráficos ao vivo (filtro, nitidez, FXAA, anisotrópico, limite de FPS, VSync, contador de FPS, esticar);
   * abas Truques e Save;
   * em português;
   * o depurador foi para Ctrl+F1.
* O FXAA não desliga mais o filtro nítido.
* Launcher:
   * perfis gráficos (Desempenho / Equilibrado / Qualidade);
   * tela cheia sem bordas;
   * seção Upscaling e ferramentas (Lossless Scaling, ReShade e OBS no modo sem bordas; DLSS e FSR 2–3 não são possíveis);
   * atalho para as teclas do teclado;
   * estado do PGO, página Saves e relatórios de sessão.
* Opções que não faziam nada foram removidas.
* Correções de memória/DMA, overflow no áudio (SPU2), execução direta do jogo e várias outras.
* Sessão de 30 minutos a partir de um save mais à frente: estável, memória sem crescer depois do aquecimento.

Limitações:

* medida em uma máquina e principalmente no início do jogo;
* 60 fps travados ainda não no combate pesado; o limite agora é o trabalho da VU1 na CPU;
* pequenos engasgos com falha de áudio em transições de área; o áudio das cutscenes em PT-BR tem um problema conhecido
  de alinhamento;
* se notar falhas de imagem, desligue **Antecipar o fim do quadro** e relate;
* só o código do disco americano é suportado; por enquanto, só Windows.

Relate problemas em [Issues](https://github.com/Vnnc1/gow-native-pc/issues): use **Outros → Marcar um problema durante o
jogo** e depois **Outros → Relatório de testes e erros** para exportar o ZIP, e informe sua CPU/GPU.
