A native PC port of God of War (PS2, NTSC-U `SCUS-97399`). The game's code is statically recompiled from MIPS to
C++ and built on your machine from your own disc image. It is not an emulator. No game files are included or
downloaded.

> **Not 100% yet.** The game is playable, but a locked 60 fps in heavy combat is not there yet. Every release improves
> on the last; **texture packs, a Linux port and ISO mods** are planned.

### Download

* `gow-native-pc-setup.exe` (recommended): installs the launcher for your user only, with no administrator rights.
* `gow-native-pc-windows.zip`: the same files without the installer.

**Coming from v0.3.1 or earlier?** Run this setup once over your installation. Those launchers report version 1.0.0 to
3.0.1 (the releases were renumbered) and do not see 0.4.0 as newer, so they will not offer it. Your game build,
discs and saves are kept. The runtime patches changed, so the launcher then asks you to rebuild the game once
(Install → the notice at the top). Automatic updates work again from this version on.

### How to play

1. Run the setup and open God of War Launcher.
2. Install tab, three steps: Download tools → Add ISO… → Install and build. Leave **Prepare the first play** enabled.
3. Wait on the loading screen, pick a graphics profile on the Graphics page, then click PLAY.

**The release now brings its own profile-guided optimisation (PGO) profile**, trained on exactly this runtime and
patch set. The install uses it directly: no instrumented build and no training run, on any CPU. CPUs with 4 threads
or fewer, which skipped PGO before, now get it too. The game still compiles on your PC, so the first install takes
a while on small CPUs (a 2-core/4-thread laptop CPU can take over an hour). You can keep using the PC while it runs.

### Requirements

* Windows 10/11 64-bit
* x86-64 CPU with SSE4.2 (Intel Core i from ~2009, AMD FX / Ryzen from 2011); the launcher checks it before installing
* 8 GB RAM (16 GB recommended while building)
* GPU with OpenGL 4.3 (with `NV_texture_barrier` / `ARB_texture_barrier`, as Intel HD 4000–4600 drivers have) or
  newer, with the GPU maker's driver installed (NVIDIA, AMD or Intel)
* your God of War (USA, SCUS-97399) ISO, or a fan translation of it that only changes text

### What's new since v0.3.1

**New options**

* **Fast VU mode** (off by default; Launcher → Performance): VU1 code without the exact float clean-ups, like
  PCSX2's default settings. About 12% less VU1 work in a recorded combat replay; rare small differences from the
  exact mode, none visible in the scenes we checked. Worth trying on slower CPUs, where VU1 is the limit.
* **Hold instead of mashing** (accessibility, off by default; Launcher → Controls): in the minigames that ask for
  repeated presses, holding the button presses it for you; a short press stays a single press. By
  [ThisIsAkill](https://github.com/ThisIsAkill) (PR #10).
* **Launcher in French, German, Italian, Russian and Simplified Chinese**, besides English, Portuguese, Spanish and
  Turkish. The system's language is picked on first start. The in-game F1 menu stays in English for these.

**Fixes**

* **Sound effects going silent in long fights**: after about 35 s of combat the effect voices filled up and hits went
  silent until an area change. Released voices now fade to zero and free their slot.
* **Frozen pink screen**: when the GPU renderer cannot start (no OpenGL 4.3: an old GPU, the generic Microsoft Basic
  Display Adapter, Remote Desktop; or a driver that rejects the shaders), the game window stayed pink. It now says
  why and what to do, in the launcher's language.
* **"The term ...\build.ps1 is not recognized" during install**: an antivirus had quarantined the install script
  while it started. The launcher now says that a file of the installation was removed and how to restore it,
  instead of "Failed (code 1)".
* **Install failed in a folder whose name has a space** (for example `E:\God of War`): every compile failed with
  "sccache: Failed to open file for hashing".
* Running the setup over an earlier version now asks for a game rebuild when the runtime patches changed, as
  launcher updates already did.

**Under the hood**

* The VU1 interpreter's debug and recording paths no longer reserve large stack frames on every VU1 program.
* `tools/pipeline/patches.ps1` moves the runtime patch stack to a newer runtime commit with git's 3-way merge.

### Known limitations

* A locked 60 fps is not reached in heavy combat yet; the limit is the VU1 work on one CPU thread.
* On 2-core/4-thread laptop CPUs the game runs but slowly: about 20 fps in combat on an i3-10110U, where VU1 is busy
  over 90% of the time. The shipped PGO profile and Fast VU mode help, but do not reach full speed there.
* Short hitches with audio gaps can occur at area transitions; the PT-BR cutscene audio has a known
  channel-alignment issue.
* Only the USA disc's code is supported. Windows only for now.

Please report problems in [Issues](https://github.com/Vnnc1/gow-native-pc/issues): **Other → Mark a problem during play**,
then **Other → Test and bug report** to export a ZIP, and include your CPU/GPU. For slow games, turn on
**Audio and compilation diagnostics** first and play a couple of minutes: the report then shows where the time goes.

### Português

Port nativo para PC de God of War (PS2, NTSC-U `SCUS-97399`). O código do jogo é recompilado de MIPS para C++ e
compilado no seu PC a partir da sua própria ISO. Não é um emulador. Nenhum arquivo do jogo é incluído ou baixado.

> **Ainda não está 100%.** O jogo é jogável, mas 60 fps travados no combate pesado ainda não chegaram. Cada versão
> melhora; **texture packs, port para Linux e mods de ISO** estão planejados.

**Vem da v0.3.1 ou anterior?** Rode este setup uma vez por cima da instalação. Esses launchers informam a versão
1.0.0 a 3.0.1 (as versões foram renumeradas) e não veem a 0.4.0 como mais nova, então não a oferecem. Seu jogo,
ISOs e saves continuam. Os patches do runtime mudaram, então o launcher pede para recompilar o jogo uma vez (aviso no
topo da aba Instalação). A partir desta versão as atualizações automáticas voltam a funcionar.

Como jogar:

1. Rode o `gow-native-pc-setup.exe` e abra o God of War Launcher.
2. Na aba Instalação: Baixar ferramentas → Adicionar ISO… → Instalar e compilar. Deixe **Preparar a primeira jogatina** ligado.
3. Espere na tela de carregamento, escolha um perfil na página Gráficos e clique em JOGAR.

**A versão agora traz o próprio perfil de otimização guiada por perfil (PGO)**, treinado exatamente neste runtime e
conjunto de patches. A instalação o usa direto, sem build instrumentado nem sessão de treino, em qualquer CPU. CPUs
de até 4 threads, que antes ficavam sem PGO, agora também recebem. O jogo continua sendo compilado no seu PC, então
a primeira instalação demora em CPUs pequenas (um notebook de 2 núcleos/4 threads pode passar de uma hora).

Requisitos: Windows 10/11 64 bits; CPU x86-64 com SSE4.2 (o launcher confere antes de instalar); 8 GB de RAM
(16 GB recomendados ao compilar); GPU com OpenGL 4.3 (com `NV_texture_barrier`/`ARB_texture_barrier`, como os drivers
das Intel HD 4000–4600) ou mais nova, com o driver do fabricante instalado (NVIDIA, AMD ou Intel); a ISO do God of
War (EUA, SCUS-97399).

Novidades:

* **Modo VU rápida** (desligado por padrão; Launcher → Desempenho): código da VU1 sem as correções exatas de ponto
  flutuante, como nas configurações padrão do PCSX2. Cerca de 12% menos trabalho de VU1 num replay de combate
  gravado; diferenças pequenas e raras em relação ao modo exato, nenhuma visível nas cenas conferidas. Vale testar em
  CPUs mais lentas, onde a VU1 é o limite.
* **Segurar em vez de apertar sem parar** (acessibilidade, desligado por padrão; Launcher → Controles): nos
  minigames que pedem toques repetidos, segurar o botão aperta por você; um toque curto continua sendo um toque. Por
  [ThisIsAkill](https://github.com/ThisIsAkill) (PR #10).
* **Launcher em francês, alemão, italiano, russo e chinês simplificado**, além de inglês, português, espanhol e turco.
  O idioma do sistema é escolhido na primeira abertura; o menu F1 do jogo fica em inglês nesses idiomas.
* **Efeitos sonoros sumindo em lutas longas**: depois de uns 35 s de combate as vozes de efeitos lotavam e os golpes
  ficavam mudos até trocar de área. Agora as vozes liberadas caem até zero e liberam o espaço.
* **Tela rosa congelada**: quando o renderizador da GPU não consegue iniciar (sem OpenGL 4.3: GPU antiga, o
  Adaptador de Vídeo Básico da Microsoft, Área de Trabalho Remota; ou um driver que recusa os shaders), a janela
  ficava rosa. Agora ela diz o motivo e o que fazer, no idioma do launcher.
* **"O termo ...\build.ps1 não é reconhecido" na instalação**: um antivírus tinha posto o script de instalação em
  quarentena. O launcher agora avisa que um arquivo da instalação foi removido e como restaurá-lo, em vez de
  "Falhou (código 1)".
* **A instalação falhava numa pasta com espaço no nome** (por exemplo `E:\God of War`): toda compilação falhava com
  "sccache: Failed to open file for hashing".
* Rodar o setup por cima de uma versão anterior agora pede para recompilar o jogo quando os patches do runtime
  mudaram, como as atualizações do launcher já faziam.

Limitações: 60 fps travados ainda não no combate pesado (o limite é o trabalho da VU1 numa thread); em notebooks de
2 núcleos/4 threads o jogo roda, mas lento (cerca de 20 fps em combate num i3-10110U, com a VU1 ocupada mais de 90%
do tempo); pequenos engasgos com falha de áudio em transições; só o código do disco americano; por enquanto, só
Windows.

Relate problemas em [Issues](https://github.com/Vnnc1/gow-native-pc/issues) com o ZIP de **Outros → Relatório de testes
e erros** e informe sua CPU/GPU. Se o jogo estiver lento, ligue antes o **Diagnóstico de áudio e compilação** e jogue
uns minutos: o relatório passa a mostrar para onde vai o tempo.
