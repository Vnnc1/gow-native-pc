**English** · [Português abaixo](#português)

A native PC port of *God of War* (PS2, NTSC-U `SCUS-97399`). The game's code is statically recompiled from MIPS to
C++ and built on your machine from **your own disc image**. It is not an emulator. No game files are included or
downloaded.

## Download

- **`gow-native-pc-setup.exe`** (recommended): installs the launcher for your user only, with no administrator rights.
  It adds Start menu shortcuts and an *Apps* entry to uninstall it.

Coming from v0.1.0? Run this setup over it (v0.1.0 has no updater; from this release on the launcher updates itself). This version changes the runtime patches, so the
launcher then asks you to rebuild the game once.

## How to play

1. Run the setup and open **God of War Launcher**.
2. **Install** tab, three steps: **Download tools** → **Add ISO…** → **Install and build**.
3. Wait on the loading screen. Then click **PLAY**.

The first install takes about 20-30 minutes on our test PC (longer on CPUs with fewer cores). You can keep using the
PC while it runs.

## Requirements

- Windows 10/11 64-bit
- CPU with AVX2 and 4+ cores
- 8 GB RAM (16 GB recommended while building)
- GPU with OpenGL 4.3
- ~25 GB free
- your **God of War (USA, SCUS-97399)** ISO, or a fan translation of it that only changes text

**Visual Studio, Git and Python are no longer needed.** The launcher downloads portable build tools and the clang
compiler once into its own folder (~280 MB, nothing is installed in Windows).

## What's new since v0.1.0

### Much faster, lighter install
- **clang (llvm-mingw) is now the compiler:** the game builds in ~15 min instead of 45-60 min with MSVC, and Visual
  Studio is not needed.
- **Install in three clicks:** portable tools, then your ISO, then install. The tools step now takes under a minute
  (it took ~6).
- **The PC stays usable while building:** the build runs at low priority, leaves 2 CPU cores free, and limits
  parallel compilers by your RAM.
- **New loading screen** during the install:
  - one progress bar from start to end, with the time left;
  - the current step by name (e.g. "Recording the game's code (2:31 of 4:00)");
  - rotating tips;
  - a "Show details" button for the log;
  - your own pictures if you put some in `data\gow1\loading`;
  - at the end: "Ready! Click PLAY".
- **The first-play recording runs hidden in the background.** No window and no sound, and nothing you type can
  disturb it.
- **Faster last step:** after the recording, only the recorded vector-unit code is recompiled, not the whole game.
- Works from USB / exFAT drives.

### Performance
Measured in our scripted ship-combat test with the launcher's default settings (Xeon E5-2666 v3 + RX 580):
- **Minimum fps 51.4 → 54.6, average 56.5 → 58.4** (clang + profile-guided optimization).
- What made it faster:
  - vector unit (VU1) code without needless float clean-ups, and blocks that chain directly into one another;
  - sound mixed in batches (~14 % → ~4 % of the game thread);
  - the game's frame budget now follows the real CPU clock;
  - the IOP heap reuses freed memory.
- New optional **profile-guided optimization** (Install → More options): the game plays itself for 4 minutes and is
  rebuilt with what it learned. Allow about 30 minutes.

### Launcher
- **Controls:** remap the controller button by button (buttons captured from your controller), in addition to the
  keyboard.
- **32:9 super-ultrawide** aspect ratio (5120×1440, 3840×1080).
- **Updates from GitHub Releases:** the launcher tells you when a new version is out and updates itself.

## Known limitations

- Measured on one machine (Xeon E5-2666 v3, RX 580). Other areas and hardware are not verified yet.
- Some players report the picture freezing after a few minutes while the sound keeps going. We are investigating; logs
  and hardware details help a lot.
- "Purple/green tint": the scene sometimes turns purple or green. This is an old renderer bug, under investigation.
- Only the USA disc's code is supported (other regions differ in code).

Please report problems in [Issues](https://github.com/Vnnc1/gow-native-pc/issues), with `data\gow1\logs\build.log` /
`recomp.log` and your CPU/GPU.

## Português

Port nativo para PC de *God of War* (PS2, NTSC-U `SCUS-97399`). O código do jogo é recompilado de MIPS para C++ e
compilado no seu PC a partir da **sua própria ISO**. Não é um emulador. Nenhum arquivo do jogo é incluído ou baixado.

**Como jogar:**
1. Rode o `gow-native-pc-setup.exe` e abra o **God of War Launcher**.
2. Na aba **Instalar**, faça os três passos: **Baixar ferramentas** → **Adicionar ISO…** → **Instalar e compilar**.
3. Espere na tela de carregamento e clique em **JOGAR**.

A primeira instalação leva cerca de 20 a 30 minutos no nosso PC de teste, e dá para continuar usando o PC enquanto
isso. Quem tem a v0.1.0 deve rodar este setup por cima dela (a v0.1.0 não tem atualizador; a partir desta versão o launcher se atualiza sozinho) e recompilar o jogo uma vez.

**Requisitos:**
- Windows 10/11 64 bits;
- CPU com AVX2 e 4+ núcleos;
- 8 GB de RAM (16 GB recomendados durante a compilação);
- GPU com OpenGL 4.3;
- ~25 GB livres;
- a ISO do God of War (EUA, SCUS-97399), ou uma tradução de fãs dela que só mude textos.

**Não precisa mais de Visual Studio, Git nem Python:** o launcher baixa ferramentas portáteis e o compilador clang uma
vez, na própria pasta.

**Novidades:**
- **Compilação muito mais rápida:** o clang compila o jogo em ~15 min, contra 45-60 min com o MSVC.
- **Instalação em três cliques**, e a etapa de ferramentas agora leva menos de 1 minuto.
- **O PC continua utilizável:** a compilação roda em prioridade baixa e deixa 2 núcleos livres.
- **Nova tela de carregamento:**
  - uma barra só, com o tempo restante;
  - a etapa atual pelo nome;
  - dicas que vão trocando;
  - o botão "Ver detalhes";
  - as suas próprias imagens, se você colocar alguma em `data\gow1\loading`;
  - no fim, "Pronto! Clique em JOGAR".
- **A gravação da primeira jogatina roda escondida**, em segundo plano e sem som.
- **Etapa final mais rápida:** só o código gravado é recompilado, não o jogo inteiro.
- **Desempenho no teste de combate do navio:** mínimo de 51,4 → 54,6 fps e média de 56,5 → 58,4 fps (clang + PGO).
- **Otimização guiada por perfil**, opcional (Instalar → Mais opções).
- **Controle remapeável botão por botão**, além do teclado.
- **Proporção 32:9.**
- **Atualizações automáticas** a partir das Releases do GitHub.
- Funciona a partir de pendrive ou HD externo (exFAT).

**Limitações:**
- medida em uma máquina e só no início do jogo;
- há relatos de a imagem congelar depois de alguns minutos com o som continuando, e isso está em investigação;
- o tom roxo/verde ocasional na cena também está em investigação;
- só o código do disco americano é suportado.

Relate problemas em [Issues](https://github.com/Vnnc1/gow-native-pc/issues), com o `build.log` e o `recomp.log` de
`data\gow1\logs`.
