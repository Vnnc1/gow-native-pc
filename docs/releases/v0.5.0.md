# v0.5.0 — Experimental Linux, CHD import, regional editions and accessibility improvements

**v0.5.0 · 2026-11-02 · [Changelog](https://github.com/Vnnc1/gow-native-pc/blob/main/CHANGELOG.md)**

**English · Português abaixo**

A native PC port of **God of War (PS2)**. The game's executable is statically recompiled from MIPS to C++ and built on your machine from your own compatible disc image. **No game files are included or downloaded.**

This release introduces experimental Linux distribution, CHD import, regional build selection, a dedicated Accessibility page, keyboard/mouse improvements and fixes for cutscene audio.

**The project is still in development.** Stable 60 FPS remains the target; performance depends on hardware, settings and the scene.

## Download

- **`gow-native-pc-setup.exe` — Windows, recommended:** installs or updates the launcher for your user, without administrator rights.
- **`gow-native-pc-windows.zip`:** the Windows distribution without the installer.
- **`gow-native-pc-linux-x86_64-ubuntu26.04-experimental.run` — Linux, experimental:** installs the native launcher and build scripts.
- **`gow-native-pc-linux-x86_64-ubuntu26.04-experimental.tar.gz`:** the same Linux distribution for manual extraction.

Use the accompanying **`.sha256` files** to verify your downloads.

**Updating an existing Windows installation?** Run the setup over its current folder. Keep your game files and saves; rebuild the game when the launcher requests it so the new runtime fixes take effect.

## How to play

### Windows

1. Run `gow-native-pc-setup.exe` and open **God of War Launcher**.
2. In **Install**: **Download tools → Add ISO / CHD… → Install and build**.
3. Keep **Prepare the first play** enabled where available.
4. Choose your graphics settings, review Controls and Accessibility, then click **PLAY**.

**This release does not include a pre-trained PGO profile.** Local profile training remains available on Windows. Initial installation time depends on your CPU, RAM, storage and downloads.

### Linux — experimental

Install the system dependencies described in the [Linux guide](https://github.com/Vnnc1/gow-native-pc/blob/main/docs/linux.md), then run:

```bash
bash gow-native-pc-linux-x86_64-ubuntu26.04-experimental.run
bash "$HOME/.local/share/gow-native-pc-0.5.0/start-linux.sh"
```

Import your own compatible disc through the launcher's Install page to compile the game.

The installer accepts a **new destination directory** as its argument and refuses existing destinations to protect games and saves. It does not install system dependencies.

**The supplied binaries use Ubuntu 26.04 libraries.** This is not a universal AppImage or a validated SteamOS package. Other distributions may require rebuilding the launcher from source.

## Requirements

- **Windows:** Windows 10/11 64-bit.
- **Linux:** experimental x86-64 support; see the distribution-specific dependencies in the Linux guide.
- **CPU:** x86-64-v2, including SSE4.2/POPCNT.
- **RAM:** 8 GB; 16 GB recommended while compiling.
- **GPU:** OpenGL 4.3+, with the required texture-barrier support and the manufacturer's driver.
- **Game:** your own compatible God of War disc image.
- **Storage:** space for extracted game files, build tools and compilation output. CHD import also needs an uncompressed ISO cache.

## What's new since v0.4.0

### Experimental Linux and Steam Deck testing

- Native Linux launcher, diagnostic helper and compilation pipeline.
- Self-extracting `.run` installer and archive distribution.
- Initial gameplay and launcher startup tested in Ubuntu through WSL.
- Linux process CPU/memory diagnostics and case-sensitive disc-path fixes.

**Steam Deck testing is welcome**, but real-device performance, Steam Input, Gaming Mode and suspend/resume remain unvalidated.

### CHD import

- Import supported **CHDv5** images directly from **Add ISO / CHD…**.
- Integrity verification before conversion and recompilation.
- Converted ISOs are cached locally; source CHDs remain unchanged.
- The same game-code compatibility checks apply to ISO and CHD.

CHD support does not make an otherwise unsupported edition compatible. Unsupported CHD layouts are rejected with an explanation.

### Regional editions

- **USA:** supported base executable.
- **Asia:** the tested image contains the same executable code as USA.
- **Japan and Europe:** isolated Windows builds validated through opening ship gameplay, selectable in the launcher when registered.
- Separate regional build and save routing.
- **Demos are excluded.**

Japan and Europe require their own matching builds. A fresh installation does **not** automatically compile them through the USA pipeline. Other serials, full campaigns and regional Linux builds still need validation.

[Regional compatibility details](https://github.com/Vnnc1/gow-native-pc/blob/main/docs/disc-import.md)

### New Accessibility page

- Dedicated space for **texture packs and input assistance**.
- Select PCSX2-format PNG replacement packs to customize the game's appearance.
- Original game assets remain unchanged.
- Packs are not included; compatibility and memory usage depend on the files used.

### Keyboard and mouse improvements

- **Ctrl + Space** and **Ctrl + WASD** preserve held gameplay actions, including grabbing and moving objects.
- Default keyboard evade uses **Alt + WASD**.
- Optional **shake/rotate stick assistance**, using **G by default**, for minigames that request analog-stick gestures.
- Assistance stops when the key is released or focus is lost.
- Individually selectable **L1, L2, R1 and R2** repetition.
- QTE repetition pauses during button combinations to avoid interrupting held actions.

### Sound and cutscenes

- Fixed stale audio packets from one movie corrupting the next movie's channel alignment and PT-BR voices.
- The measured PT-BR scene now matches its source audio within rounding error; USA remained unchanged.
- Previous fixes for sound effects disappearing during long fights are retained.

This does not restore video content missing from modified discs or guarantee that every cutscene and transition is fixed.

### Compilation and performance

- Large native IOP modules now compile in parallel parts.
- In the recorded Xeon/Clang test, the longest compilation unit dropped from **126.5 seconds to 24.5 seconds**.
- This measures one compilation unit, **not the entire installation**.
- Work continues to reduce recompilation time and improve slower PCs toward v1.0.0.

Existing VU1 optimizations, Fast VU mode and Windows PGO remain available. **A locked 60 FPS across all mid-range computers or the full campaign has not been established.**

### Graphics and external tools

Internal resolution scaling, sharpening, FXAA, anisotropic filtering and borderless mode remain available.

External scaling/capture tools can use the borderless window. **DLSS—including DLSS 5—is not integrated into this port.** External frame generation does not increase the game's simulation rate.

### Other improvements

- Verified **xdelta/VCDIFF ISO patching**, preserving the original disc.
- Regional installation validation and isolated saves.
- Expanded diagnostics, regression tests and bilingual documentation.

## Known limitations

- Heavy combat and slower CPUs can still run below 60 FPS.
- Only initial areas have received detailed regional validation.
- Some texture packs can produce transparent enemies; the exact pack-versus-renderer cause remains unresolved.
- Audio gaps or stutters may still occur during transitions.
- Linux remains experimental and depends on compatible system libraries.
- Japan/Europe Linux builds and real Steam Deck gameplay remain unvalidated.

Report problems in [Issues](https://github.com/Vnnc1/gow-native-pc/issues). Use **Other → Mark a problem during play**, then export a ZIP through **Other → Test and bug report**. Include your CPU, GPU, operating system, disc edition and whether a texture pack was enabled.

# Português

**v0.5.0 — Linux experimental, importação CHD, edições regionais e melhorias de acessibilidade**

Port nativo para PC de **God of War (PS2)**. O executável do jogo é recompilado estaticamente de MIPS para C++ e compilado na sua máquina a partir da sua própria imagem de disco compatível. **Nenhum arquivo do jogo é incluído ou baixado.**

Esta versão traz distribuição Linux experimental, importação CHD, seleção de builds regionais, uma tela dedicada à Acessibilidade, melhorias de teclado/mouse e correções no áudio das cutscenes.

**O projeto continua em desenvolvimento.** A meta permanece em 60 FPS estáveis; o desempenho depende do hardware, das configurações e da cena.

## Downloads

- **`gow-native-pc-setup.exe` — Windows, recomendado:** instala ou atualiza o launcher para seu usuário, sem exigir administrador.
- **`gow-native-pc-windows.zip`:** distribuição Windows sem instalador.
- **`gow-native-pc-linux-x86_64-ubuntu26.04-experimental.run` — Linux experimental:** instala o launcher nativo e os scripts de compilação.
- **`gow-native-pc-linux-x86_64-ubuntu26.04-experimental.tar.gz`:** a mesma distribuição Linux para extração manual.

Use os arquivos **`.sha256`** correspondentes para verificar os downloads.

**Já tem uma instalação Windows?** Execute o setup sobre a pasta atual. Preserve seus arquivos e saves; recompile quando o launcher solicitar para aplicar as novas correções do runtime.

## Como jogar

### Windows

1. Execute `gow-native-pc-setup.exe` e abra o **God of War Launcher**.
2. Na aba **Instalação**: **Baixar ferramentas → Adicionar ISO / CHD… → Instalar e compilar**.
3. Mantenha **Preparar a primeira jogatina** habilitado quando disponível.
4. Escolha os ajustes gráficos, confira Controles e Acessibilidade e clique em **JOGAR**.

**Esta versão não inclui perfil PGO pré-treinado.** O treinamento local continua disponível no Windows. O tempo da primeira instalação depende da CPU, RAM, armazenamento e downloads.

### Linux — experimental

Instale as dependências indicadas no [guia Linux](https://github.com/Vnnc1/gow-native-pc/blob/main/docs/linux.md) e execute:

```bash
bash gow-native-pc-linux-x86_64-ubuntu26.04-experimental.run
bash "$HOME/.local/share/gow-native-pc-0.5.0/start-linux.sh"
```

Importe sua própria imagem compatível pela aba Instalação para recompilar o jogo.

O instalador aceita uma **nova pasta de destino** como argumento e recusa pastas existentes para preservar jogos e saves. Ele não instala dependências do sistema.

**Os binários fornecidos usam bibliotecas do Ubuntu 26.04.** Não é um AppImage universal nem um pacote SteamOS validado. Outras distribuições podem exigir recompilar o launcher.

## Requisitos

- **Windows:** Windows 10/11 de 64 bits.
- **Linux:** suporte x86-64 experimental; consulte as dependências no guia.
- **CPU:** x86-64-v2, incluindo SSE4.2/POPCNT.
- **RAM:** 8 GB; 16 GB recomendados durante a compilação.
- **GPU:** OpenGL 4.3+, com suporte necessário a texture barriers e driver do fabricante.
- **Jogo:** sua própria imagem de disco compatível de God of War.
- **Armazenamento:** espaço para arquivos extraídos, ferramentas e compilação. A importação CHD também exige um cache de ISO descomprimida.

## Novidades desde a v0.4.0

### Linux experimental e testes no Steam Deck

- Launcher, coletor de diagnóstico e pipeline de compilação nativos para Linux.
- Instalador autoextraível `.run` e distribuição em arquivo compactado.
- Inicialização do launcher e gameplay inicial testados no Ubuntu pelo WSL.
- Diagnósticos de CPU/memória e correções de caminhos sensíveis a maiúsculas/minúsculas.

**Testes no Steam Deck são bem-vindos**, mas desempenho no aparelho real, Steam Input, Gaming Mode e suspensão/retomada ainda não foram validados.

### Importação de CHD

- Importação de imagens **CHDv5 suportadas** pela opção **Adicionar ISO / CHD…**.
- Verificação de integridade antes da conversão e recompilação.
- ISOs convertidas ficam em cache local; os CHDs originais são preservados.
- ISO e CHD passam pelas mesmas verificações de compatibilidade do código.

O suporte a CHD não torna uma edição incompatível automaticamente jogável. Estruturas CHD não suportadas são recusadas com uma explicação.

### Edições regionais

- **EUA:** executável-base suportado.
- **Asia:** a imagem testada contém código idêntico ao USA.
- **Japão e Europa:** builds Windows isoladas, validadas no navio inicial e selecionáveis no launcher após o registro.
- Separação de builds e saves por região.
- **Demos são excluídas.**

Japão e Europa exigem suas próprias builds correspondentes. Uma instalação nova **não** as recompila automaticamente pela pipeline USA. Outros seriais, campanhas completas e builds Linux regionais ainda precisam de validação.

[Detalhes da compatibilidade regional](https://github.com/Vnnc1/gow-native-pc/blob/main/docs/disc-import.md)

### Nova tela de Acessibilidade

- Espaço dedicado a **texture packs e assistência aos controles**.
- Seleção de packs de substituições PNG no formato PCSX2 para personalizar o visual.
- Preservação dos arquivos originais do jogo.
- Packs não acompanham o projeto; compatibilidade e consumo de memória dependem dos arquivos utilizados.

### Melhorias de teclado e mouse

- **Ctrl + Espaço** e **Ctrl + WASD** preservam ações seguradas, incluindo agarrar e movimentar objetos.
- Esquiva padrão do teclado em **Alt + WASD**.
- Assistência opcional para **alternar direções ou girar o analógico**, usando **G por padrão**, nos minijogos que pedem esses movimentos.
- A assistência para ao soltar a tecla ou perder o foco.
- Repetição de **L1, L2, R1 e R2** selecionável individualmente.
- Repetição de QTE pausada durante combinações para não interromper ações seguradas.

### Som e cutscenes

- Corrigidos pacotes de áudio restantes de um vídeo que corrompiam os canais e as vozes PT-BR do vídeo seguinte.
- A cena PT-BR medida passou a corresponder ao áudio de origem dentro do erro de arredondamento; USA permaneceu inalterada.
- Mantidas as correções anteriores dos efeitos sonoros que desapareciam em lutas longas.

Isso não restaura vídeos ausentes em discos modificados nem garante que todas as cutscenes e transições estejam corrigidas.

### Compilação e desempenho

- Módulos IOP nativos grandes agora são compilados em partes paralelas.
- No teste Xeon/Clang registrado, a unidade mais demorada caiu de **126,5 segundos para 24,5 segundos**.
- Essa medição representa uma unidade de compilação, **não a instalação inteira**.
- O trabalho continua para reduzir a recompilação e melhorar computadores mais fracos rumo à v1.0.0.

As otimizações de VU1, o modo VU rápida e o PGO no Windows continuam disponíveis. **60 FPS cravados em todos os computadores intermediários ou na campanha completa ainda não foram comprovados.**

### Gráficos e ferramentas externas

Continuam disponíveis resolução interna, nitidez, FXAA, filtro anisotrópico e modo sem bordas.

Ferramentas externas de escala/captura podem usar a janela sem bordas. **DLSS — inclusive DLSS 5 — não está integrado neste port.** Geração externa de quadros não aumenta a velocidade da simulação do jogo.

### Outras melhorias

- Aplicação verificada de patches **xdelta/VCDIFF**, preservando a ISO original.
- Validação de instalações regionais e saves isolados.
- Ampliação dos diagnósticos, testes de regressão e documentação bilíngue.

## Limitações conhecidas

- Combate pesado e CPUs mais fracas ainda podem ficar abaixo de 60 FPS.
- A validação regional detalhada cobre principalmente as áreas iniciais.
- Alguns texture packs podem deixar inimigos transparentes; a causa exata entre pack e renderizador continua sem isolamento.
- Ainda podem ocorrer falhas de áudio ou engasgos em transições.
- Linux permanece experimental e depende de bibliotecas compatíveis.
- Builds Linux Japão/Europa e gameplay no Steam Deck real ainda não foram validados.

Relate problemas em [Issues](https://github.com/Vnnc1/gow-native-pc/issues). Use **Outros → Marcar um problema durante o jogo** e depois exporte o ZIP em **Outros → Relatório de testes e erros**. Informe CPU, GPU, sistema operacional, edição do disco e se havia algum texture pack ativado.
